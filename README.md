# Система учёта студентов и оценок

Учебное настольное WPF-приложение: регистрация студентов, добавление оценок по предметам и расчёт среднего балла. Данные хранятся **только в оперативной памяти** и исчезают после закрытия программы; приложение не предназначено для реальных персональных данных.

## Требования

- Windows 10/11 для запуска WPF;
- .NET SDK 9 и Git;
- доступ к NuGet при первом восстановлении пакетов.

SDK 9 выбран по требованиям задания; для дальнейшего использования необходимо проверить срок его поддержки и запланировать обновление платформы. На Linux можно собрать проект с Windows-targeting и запустить тесты ядра, но не открыть WPF-окно.

## Получение и запуск в Git Bash

```bash
git clone https://github.com/Layh0/student-records-and-grades-system.git
cd student-records-and-grades-system
dotnet restore
dotnet build
dotnet test
dotnet run --project student-records-and-grades-system
```

В окне введите имя и группу, добавьте студента и выберите его. Введите предмет и целую оценку 2–5; таблица и среднее обновятся. Если студент не выбран или ввод некорректен, появится предупреждение.

## Устройство и документация

`StudentRecords.Core` содержит реестр студентов, контракт поиска и сервис оценок; `student-records-and-grades-system` - WPF-интерфейс; `StudentRecords.Tests` - автоматические проверки. Сервис пишет диагностические события через `System.Diagnostics.Trace`; для их просмотра нужен подключённый listener (например, окно Output в отладчике Visual Studio). Имена студентов в события не записываются.
