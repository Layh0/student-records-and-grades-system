# Контракты модулей, версия 1

Контракты внутренние, вызовы синхронные в одном процессе. Названия ниже - запланированный интерфейс для этапа 3; изменения нужно отразить здесь и в тестах. Сетевой API и формат JSON не применяются.

## Протокол 1. Поиск студента

| Пункт | Описание |
|---|---|
| Инициатор → получатель | `GradeService` → реализация `IStudentLookup` в `StudentRegistry` |
| Назначение | Проверить принадлежность оценки существующему студенту. |
| Механизм / точка входа | Прямой синхронный вызов `Find(Guid studentId)`. |
| Запрос | Идентификатор студента `Guid`. |
| Успех | `Student` с `Id`, `FullName`, `Group`. |
| Ошибки | Нет студента: возвращается `null`; сервис оценок сообщает `ArgumentException`. Непустой `Guid` не означает существование записи. |
| Таймаут | Не задан: локальный поиск в памяти, внешнего ожидания нет. |
| Повтор | Автоматических повторов нет; повторять можно после исправления идентификатора. |
| Аутентификация | Не применяется к внутреннему вызову; система не реализует авторизацию. |
| Версия | 1; изменения контракта отражаются в документации и тестах. |

Пример: `Find(studentId)` → `Student(studentId, "Иван Петров", "ИС-21")`; неизвестный id → `null`.

## Протокол 2. Регистрация оценки и получение среднего

| Пункт | Описание |
|---|---|
| Инициатор → получатель | WPF → `GradeService`. |
| Назначение | Записать оценку существующего студента и получить его оценки и среднее. |
| Механизм / точка входа | Прямой синхронный вызов `AddGrade(Guid studentId, string subject, int value)` и `GetGrades(Guid studentId)`. |
| Запрос | `studentId`: Guid; `subject`: непустая строка; `value`: целое число от 2 до 5. |
| Успех | `Grade` с идентификатором студента, предметом и значением; список записей для просмотра. Среднее рассчитывается отдельно; пустой набор даёт `null`. |
| Ошибки | `ArgumentException` для неизвестного студента (в том числе при чтении оценок и среднего) или пустого предмета; `ArgumentOutOfRangeException` для значения вне 2–5. UI выводит понятное сообщение. |
| Таймаут | Не задан: вычисления в памяти и без сетевых обращений. |
| Повтор | Автоматического повтора нет: повторный `AddGrade` создаёт новую запись и не является идемпотентным. |
| Аутентификация | Не применяется, локальное учебное приложение без входа в систему. |
| Версия | 1; обновлять описание и тесты одновременно с изменением сигнатур. |

Пример: `AddGrade(studentId, "Математика", 5)` → запись с этими полями; `AddGrade(studentId, "Математика", 6)` → `ArgumentOutOfRangeException`.

## Модели

- `Student`: `Guid Id`, `string FullName`, `string Group`.
- `Grade`: `Guid StudentId`, `string Subject`, `int Value`.
- Списки являются снимками данных, а не внешним доступом к изменяемой коллекции сервиса.
