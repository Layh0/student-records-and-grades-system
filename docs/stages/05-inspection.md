```text
dotnet build                       → успешно, 0 warnings, 0 errors
dotnet test                        → всего 15, успешно 15, ошибок 0, пропущено 0
```

Первоначальная проверка форматирования завершилась кодом 2: два файла старого шаблона не соответствовали требуемой кодировке. После очистки и форматирования повторная проверка прошла. Команда `git ls-files` не обнаружила отслеживаемых файлов с именами `.env`, `*.pfx`, `*.p12`, `*.key`; это проверка имён текущих файлов, а не доказательство отсутствия секретов во всей истории.
