# Этап 3. Разработка и интеграция модулей

## Исходное состояние и ветви

Перед началом: чистая `main` на `db99575` после этапа 2. Создана `stage/03-integration`. Индивидуальная разработка моделировалась ветками `feature/03-students` и `feature/03-grades`; первая объединена до разработки второй, потому что оценкам нужен опубликованный интерфейс поиска. Это не два реальных участника команды. Контракты были зафиксированы на этапе 1 до объединения.

## Поток данных

```text
Пользователь → окно WPF → StudentRegistry.Add → Student(Id, FullName, Group)
Пользователь → окно WPF → GradeService.AddGrade → IStudentLookup.Find → StudentRegistry
                                                 → список оценок → GetAverage → окно
```

Реестр отвечает за студентов, сервис оценок - за проверку и вычисления; окно только принимает и отображает данные. Диагностические события `Trace` содержат идентификатор студента и причину отказа либо добавленное значение, без имени. См. также [контракты](../contracts.md).

## Интеграционные вопросы

Исходный шаблон был WPF на .NET Framework 4.8, тогда как задание предполагает SDK 9. Проект переведён на `net9.0-windows`, ядро - на `net9.0`, включён `EnableWindowsTargeting` для сборки на Linux. Старые неиспользуемые дизайнерские классы настроек и ресурсов исключены из компиляции. Это позволяет проверить компиляцию, но не работу окна на Linux. `IStudentLookup` отделяет сервис оценок от конкретного реестра, а неизвестный студент отклоняется на границе.

## Проверки

На Linux с SDK 9.0.320 выполнены `dotnet build student-records-and-grades-system.sln` - 0 ошибок, 0 предупреждений; `dotnet test student-records-and-grades-system.sln` - 5 пройдено, 0 ошибок. Тесты покрывают регистрацию, пустое имя, успешную интеграцию, неизвестного студента и оценку вне диапазона. Ручной запуск WPF на Windows пока не выполнен и остаётся обязательной отдельной проверкой.

Вывод: два модуля интегрированы через контракт и проверены автоматическими тестами; данные в памяти не сохраняются после выхода, а работу пользовательского окна ещё нужно подтвердить на Windows.
